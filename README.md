## 关于这个作品

这不是一张普通的歌词页，而是一封关于靠近、克制与放手的视觉书信。页面从深青夜色走向晨雾，把歌词中的情绪拆成风起、阳光、远方、追问、巷口与天光六个场景。

## 体验亮点

- 粒子汇聚成「温柔」，指针靠近时笔画会随风散开
- 「自由」随滚动逐渐舒展，形成章节高潮
- 风声、潮汐与晨光铃音由 Web Audio 实时合成
- 声景会根据当前章节自动交叉渐变
- 桌面端与移动端均提供章节导航
- 海上日出 Favicon 与 Apple Touch Icon
- 支持键盘操作、辅助阅读标签与减少动态效果偏好

## 如何聆听

页面默认静音，不会自动播放声音。点击右上角的「听见」后，当前章节的环境声景才会开启；再次点击即可关闭。

所有声音均由浏览器实时生成，没有加载外部音乐或音效文件。

## 本地运行

直接打开 `index.html` 即可浏览。若浏览器限制本地文件功能，也可以在当前目录启动一个简单的静态文件服务：

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 项目结构

```text
.
├── index.html             # 页面、样式、动画与声景逻辑
├── favicon.svg            # 浏览器标签图标
└── apple-touch-icon.png   # Apple 设备主屏幕图标
```

项目不依赖框架、第三方字体或远程资源，可以离线运行。

## 技术

HTML、CSS、JavaScript、Canvas、Web Audio API、Intersection Observer。
